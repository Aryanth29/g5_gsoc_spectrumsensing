# Data

The datasets are too large to store in this repository, so they are not
uploaded here. Download one of the following and place the file in this
folder.

## RadioML (RML2016.10a)
- Source: https://www.deepsig.ai/datasets
- Expected file: `RML2016.10a_dict.pkl`
- Reference: O'Shea, T., & West, N. (2016). Radio machine learning dataset
  generation with GNU Radio. GRCon16.

## Sig53 (TorchSig)
- Source: https://github.com/TorchDSP/torchsig
- Reference: Vallance, P., et al. (2024). TorchSig: A GNU Radio block and
  new spectrogram tools for augmenting ML training. GNU Radio Conference.

After downloading, place the file at:
    Data/RML2016.10a_dict.pkl

The notebook in `../Code/src/` loads it from this location.
