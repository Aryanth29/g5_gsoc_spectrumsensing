## Project Overview

Our project investigates spectrum sensing in GNU Radio, with a longer-term objective of supporting signal classification and unknown-signal rejection.

- Completed two open-source pull requests. Their individual objectives, implementation details, test results and current statuses are documented in the report.
- Investigated the relevance of GNU Radio block development, spectrum sensing and integrated sensing and communication (ISAC).
